# Product illustrations

Original SVG illustrations created for this tutorial. The active example uses
`backpack.svg`, `cooler.svg`, and `tent.svg`, with display-space requirements of
2, 3, and 6 units. Pictures are schematic, not to scale.

Earlier tea, coffee, and juice artwork remains available as draft material.
All illustrations depict generic products, use transparent backgrounds, and
have no external dependencies or brand logos. Slide content supplies text labels.
