Model and tutorial source

Tutorial §3.3, Example 5. Resource constraints and feasible actions follow Example 1. The demonstration begins with only the empty assortment, as in the tutorial. Audience choices test additions to one period at a time.

The original MDP stays fixed. We change which feasible joint actions the approximation represents. Each assortment is a separate option; adding Product 2 only does not combine it with Product 1.

Five feasible assortments exist in each period. Their resource use satisfies 2a₁ + 10a₂ + 8a₃ ≤ 14 and 3a₁ + 18a₂ + 15a₃ ≤ 20. The empty assortment is counted because its probability weight is represented in the model.

All products start in their initial state. An unoffered product stays there. There are two decision periods and no terminal reward.

The reference value of 49 comes from solving this small example with all five feasible assortments in both periods. It is a teaching reference, not an assumption that the full model can be enumerated in large applications. This example does not establish that every MDP needs equally few assortments.

Every collection was solved with SciPy / HiGHS. Policy profit exactly evaluates independent draws of whole assortments from the optimized period weights. Matching the full LP objective does not by itself establish an optimal MDP policy.

Pricing uses the current LP dual solution. Its score is not the final profit gain. Positive scores can require several additions before strict improvement. No positive score in either period certifies the objective of the LP containing all feasible actions.
